# Summaries of sources

Summaries of the texts held in the local `library/` (see `library/README.md` for the index and
identifiers). Each file says who wrote it and what Fable checked. Most were written by Sol, a model
from another lab, so they also record where an outside reader thinks this project is wrong.

| File | Covers |
|---|---|
| `core-guides.md` | Gopen and Swan 1990; Whitesides 2004; Mensh and Kording 2017; Pinker 2014, chapter 3 |
| `pinker-style-and-coherence.md` | Pinker 2014, chapters 2, 4 and 5 |
| `shorter-guides.md` | Zhang 2014; Bates College 2008; Nature's summary paragraph; Pierce 2017; the APS report on Pinker; Brown, Pressland and Rogers 1993 |
| `evidence.md` | Ten studies of writing style, editing and AI revision |
| `others-skills.md` | Five public agent skills for scientific writing |

`docs/process.md` draws these together and says where the sources conflict.
